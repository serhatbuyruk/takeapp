By default in Odoo, when you click on a Many2one field, Odoo will open the Many2one field in the current browser tab, which can sometimes be inconvenient. With this app, you can open the Many2one field in a new browser tab, or you can open the Many2one field using a popup.



Many2one Field Behaviour Configuration

Odoo Default: Open Many2one field by Odoo's default behavior.
New Tab: Open Many2one field by new browser tab.
Show Popup: Open Many2one field by showing popup.

You can override the settings by adding the "new_tab" or "show_popup" into options attribute for the field tag.
<field name="user_id" options="{"new_tab": True}"/>
<field name="partner_id" options="{"show_popup": True}"/>
