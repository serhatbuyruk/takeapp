Overview

This module allows you to receive payments using PayTr payment provider.
This module needs phonenumbers python module .Before installing the module make sure it is loaded
Paytr Notification URL Should be: https://yourdomain/payment/trpay/webhook

Features

Receive payment by credit card
Advantage,Axess,Bankkart,Bonus,CardFinans,maximum,Paraf,World
MasterPass,Bkm express,ptt,troy
Currency wise amount specification.
Partial Refund.

Screenshots

Goto Payment paroviders and click on Paytr payment provider

Enter the merchant information provided by Paytr and enable it.

Adjust paytr payment plugin settings.

Can pay without installments.

Or you can pay in installments (if activated in the settings).

Or you can pay with other payment methods.

If you want, you can make a full or partial refund.
